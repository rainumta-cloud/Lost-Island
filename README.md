# 🏝️ SOS Island: 10 Days

เกมเอาชีวิตรอดแบบข้อความ (ภาษาอังกฤษแบบง่าย เด็กอ่านได้) เลือกเส้นทางเองได้
เขียนด้วย HTML + CSS + JavaScript ล้วน — ไม่ต้อง build ไม่ใช้ Node.js ไม่ใช้ Database
ความคืบหน้าทั้งหมดเก็บใน **Cookie** ของเบราว์เซอร์

- บริหาร 4 ค่าพร้อมกัน: ❤️ Health ⚡ Energy 🍖 Food 😊 Happy
- เหตุการณ์ 28 แบบ (สุ่มตามเงื่อนไข 26 แบบ + วันแรกและวันสุดท้าย) และฉากจบ 11 แบบ รวมฉากจบลับ
- 🌅 **Daily Island**: ทุกคนได้เกาะเดียวกันในวันนั้น เล่นได้วันละครั้ง สะสม streak
- 🎲 **Random Island**: เล่นได้ไม่จำกัด
- ✨ เอฟเฟกต์: พิมพ์ทีละตัว, ฉากเปลี่ยนวันพระอาทิตย์ขึ้น, ป๊อปอัปได้ไอเท็ม, จอสั่นตอนโดนดาเมจ, หัวใจลอยตอนฟื้นพลัง, confetti/พลุตอนจบดี, นก ปลา ดาวตก ฝน ฟ้าแลบในฉาก
- 🔊 เสียงบรรยากาศ: คลื่นทะเลเบาๆ เปลี่ยนเป็นฝน/พายุ (มีฟ้าร้อง) ตามฉาก — สร้างสดด้วย Web Audio ไม่ใช้ไฟล์เสียง มีปุ่มปิดเสียงมุมซ้ายบน (จำค่าไว้ใน Cookie)
  - เบราว์เซอร์ไม่อนุญาตให้เล่นเสียงก่อนผู้เล่นแตะหน้าจอ เสียงจะเริ่มหลังแตะ/คลิกครั้งแรก
- ถ้าเครื่องตั้งค่า "ลดการเคลื่อนไหว" (Reduce motion) เกมจะปิดเอฟเฟกต์ที่ขยับแรงๆ ให้อัตโนมัติ

## ขึ้น Netlify (ฟรี)

1. เข้า <https://app.netlify.com/drop> (หรือ Add new site → Deploy manually)
2. ลากโฟลเดอร์นี้ทั้งโฟลเดอร์ไปวาง
3. ได้ลิงก์ `https://xxxx.netlify.app` ไปเล่นได้เลย (Cookie ทำงานผ่าน https อัตโนมัติ)

## เล่นบนเครื่อง

ดับเบิลคลิก `index.html` ได้เลย
> Chrome/Edge ไม่ยอมเก็บ Cookie ให้ไฟล์ที่เปิดจาก `file://` เกมจะสลับไปบันทึกใน localStorage ให้อัตโนมัติ
> (มีข้อความบอกที่ท้ายหน้า) พอขึ้นเว็บจริงก็จะกลับมาใช้ Cookie เอง

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `css/style.css` | หน้าตา ฉากเกาะ แอนิเมชัน |
| `js/story.js` | **เนื้อเรื่องทั้งหมด** — เหตุการณ์ ตัวเลือก ผลลัพธ์ ไอเท็ม ฉากจบ |
| `js/engine.js` | กติกาเกม (สุ่มเหตุการณ์ คำนวณค่ากลางคืน ตัดสินฉากจบ) ไม่มีโค้ดหน้าจอ |
| `js/storage.js` | อ่าน/เขียน Cookie (`tbs_save`, `tbs_meta`, `tbs_pref`) |
| `js/fx.js` | เอฟเฟกต์ภาพทั้งหมด |
| `js/audio.js` | เสียงบรรยากาศ (Web Audio) |
| `js/ui.js` | วาดหน้าจอตามค่าในเกม และรับการกดของผู้เล่น |

## เพิ่มเหตุการณ์ใหม่

เพิ่ม object ลงใน `TBS.EVENTS` ใน `js/story.js` (คำอธิบายทุก field อยู่ที่หัวไฟล์) ตัวอย่าง:

```js
{
  id: 'coconut', icon: '🥥', title: 'Falling Coconut', repeat: true, weight: 1,
  text: 'Thump! A big coconut falls right next to you.',
  choices: [
    { text: 'Crack it open and eat', outcomes: [
      { text: 'Sweet and yummy!', fx: { food: 10, mood: 5 } }
    ] },
    { text: 'Climb up for more', outcomes: [
      { p: .7, text: 'You get a whole bunch!', fx: { energy: -15, food: 25 } },
      { text: 'You slip and land on your bottom. Ouch!', fx: { energy: -15, hp: -10 }, cause: 'injury' }
    ] }
  ]
}
```

- `id` ต้องเป็นภาษาอังกฤษและไม่ซ้ำ เพราะเป็นค่าที่เก็บลง Cookie
- ใส่ `weather: 'rain'` หรือ `'storm'` หรือ `'night'` ฉากด้านบนและเสียงบรรยากาศจะเปลี่ยนตามให้เอง
